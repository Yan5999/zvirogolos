# Звіроголос

Затишна 2D-гра-дослідження на Godot 4.7 (GDScript). Край замовк: звірі сховалися й забули свої голоси.
Гравець шукає 30 звірів у чотирьох біомах (ліс, пустеля, озеро, сніги), дає їм імена та записує їм голоси з мікрофона.

## Керування

| Дія | Клавіатура | Геймпад |
|---|---|---|
| Рух / біг | WASD або стрілки / Shift | стік / RB |
| Ім'я та голос звіра поруч | E | X |
| Зоопарк | Tab або Z | Y |
| Мапа | M | Back |
| Чекати до світанку/сутінків | N | — |
| Пауза | Esc | Start |

## Механіки

- **День і ніч.** Доба триває 6 хвилин (`GameState.DAY_LENGTH`). Деякі види виходять лише вночі або лише вдень
  (`SpeciesData.active_time`). Сплячий звір ледь шелестить, а HUD підказує, коли повернутися.
- **Підказки.** У зоопарку є загадка про наступного ненайденого звіра: біом, схованка й час доби.
- **Червоний список МСОП.** Кожен вид має охоронний статус (`SpeciesData.status`). У зоопарку він показаний кольоровою міткою та підказкою.
- **Хор.** Усі записані голоси звучать разом: кнопка «Хор» у зоопарку, а також фінал після того, як знайдено всіх.
- **Новий світ.** Скидання прогресу в меню генерує світ з новим seed (зберігається в `save.json`).

## Структура

- `autoload/` — `GameState` (світ, записи, час доби), `SaveManager`, `AudioManager` (мікрофон, пул голосів, хор), `SteamManager` (необов'язково, через GodotSteam).
- `scripts/world/` — генерація світу, тайли, `DayNight` (тонування + ліхтар гравця).
- `scripts/animal/`, `scripts/player/` — процедурний арт. Щоб замінити звіра на спрайт, заповніть `sprite` у `resources/species/*.tres`.
- `scripts/ui/` — HUD, зоопарк, мапа, діалог запису, `StoryPanel` (інтро та фінал).
- `tools/` — генератор видів, скриншоти, smoke-тести.

## Тести

```
godot --headless --path . res://tools/smoke_test.tscn
```

## Steam-досягнення

`ACH_FIRST_FIND`, `ACH_FIRST_VOICE`, `ACH_FULL_ZOO`, `ACH_NIGHT_FIND`, `ACH_FULL_CHORUS`,
`ACH_BIOME_FOREST`, `ACH_BIOME_DESERT`, `ACH_BIOME_LAKE`, `ACH_BIOME_SNOW`. Їх треба завести в Steamworks з тими самими іменами.
